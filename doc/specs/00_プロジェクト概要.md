# プロジェクト概要

最終更新: 2026-08-18

---

## このリポジトリについて

**筋トレの記録・進捗管理モバイルアプリ**（Flutter + SQLite・完全オフライン）。

インターバル中の最小タップで重量・回数を記録し、履歴とカレンダーでトレーニングの振り返りを支援する。MVP では記録と履歴に集中し、1RM 算出・目標値提示は後続フェーズとする。

- **企画書**: Google Drive `20260523_企画書_筋トレ記録アプリ`
- **Agent 運用**: [AGENTS.md](../../AGENTS.md) · [agent_core.mdc](../../.cursor/rules/agent_core.mdc)

---

## 目的（TO-BE）

- 要件・設計・実装状況を `doc/specs/` で一元管理する
- MVP（Phase 1）で重量×回数の記録・履歴・タイマー・ダーク UI を提供する
- エージェントは Phase skills に従い `src/workout_record_app/` を実装する

---

## スコープ

| 項目 | 内容 |
|---|---|
| プロジェクト名 | workout_record_app |
| 対象ユーザー | 個人で筋トレを行う利用者（オフラインジム利用を想定） |
| 技術スタック | Flutter / SQLite（sqflite）/ 完全オフライン |
| MVP（Phase 1） | 種目マスタ、記録 CRUD、履歴・カレンダー、タイマー、ダーク UI |
| Phase 2 | 1RM 自動計算（Epley 法） |
| Phase 3（Could） | グラフ、CSV、体重記録、テーマカラー切替 |
| 非スコープ（MVP） | クラウド同期、外部 API、推奨トレーニング強度の提示、1RM 表示 |
