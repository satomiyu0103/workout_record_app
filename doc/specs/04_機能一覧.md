## 採番ルール

### コード体系

```
[TYPE]-[CATEGORY]-[NNN]

TYPE:  FR = 機能要件  /  NFR = 非機能要件

CATEGORY（FR 用）:
  EXR   = 種目マスタ
  REC   = トレーニング記録
  CAL   = 計算
  HIS   = 履歴・カレンダー
  VIS   = 可視化・グラフ
  SYS   = システム・UI 基盤

CATEGORY（NFR 用）:
  SEC   = セキュリティ
  PERF  = パフォーマンス
  OPS   = 運用・保守

NNN: カテゴリ内の連番（001〜）。欠番は振り直さない。
```

### 運用ルール

- 新機能追加時: 該当カテゴリの最大連番 + 1 で採番する
- 機能廃止時: 実装状況を「廃止」に変更する（行は削除しない）
- カテゴリ追加時: このファイルの CATEGORY 定義に追記する

## 実装状況の凡例

| 値 | 意味 |
|---|---|
| 未着手 | 実装していない |
| 実装済 | 実装・動作確認済み |
| 廃止 | スコープ外にした（Wont） |
| 検討中 | 要件が未確定 |
