### 主要パスの責務

| パス | 責務 |
|---|---|
| `lib/presentation/` | 画面・Widget。FR-SYS-003 ダークテーマ適用 |
| `lib/application/` | ユースケース（記録保存・履歴取得・タイマー） |
| `lib/domain/` | エンティティ・リポジトリ IF・純粋計算 |
| `lib/data/` | SQLite DAO・マイグレーション |
| `lib/core/theme/` | [DESIGN.md](../../DESIGN.md) のカラートークン |
| `test/unit/` | domain / application のユニットテスト |
| `test/widget/` | 主要画面の Widget テスト |
